## Code navigation (mandatory for agents)

Before broad repository search or reading large files:

1. Open `docs/map/ATLAS.md` and follow its **Navigation protocol**.
2. Open the matching `docs/map/modules/<module-id>.md`.
3. Prefer module-scoped search and symbol windows from `docs/map/generated/` over full-file reads.

Do not start with repo-wide fuzzy search for generic names. Do not read entire large files “for context” when an outline/symbol index exists.
